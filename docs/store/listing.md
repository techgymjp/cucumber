## 日本語

**アプリ名**（30 文字以内）

```
きゅうり輪切り名人
```

**簡単な説明**（80 文字以内）

```
連打で包丁をさばき、きゅうりを薄く輪切り！30秒で薄さと速さを競う、効果音つきの包丁さばきゲーム
```

**詳しい説明**

```
30秒で、きゅうりをどこまで薄く切れるか。

まな板の上を、きゅうりが包丁に向かってどんどん流れてくる。しかも時間がたつほど速くなる。
画面をタップして包丁をトン！ 連打が速いほど輪切りは薄くなり、得点もアップ。
1.0mm未満の「神業」を連発して、伝説のきゅうり仙人を目指せ！

■ すばやく、うすく、切りまくれ
・切った1枚ごとに厚さをミリ単位で判定（神業／極うす／うすい／ふつう／ぶあつい）
・3.5mm以下を続けるとコンボ。点数は最大3倍に
・次のきゅうりが入ってくる間に切ると「空振り」。リズムよく切るのがコツ
・終わったら、切った枚数・包丁さばき（回/秒）・平均の厚さ・いちばん薄い1枚を表示

■ 5種類の野菜に挑戦
・きゅうり：タップで切れる
・茄子：皮がすべるので、切れるまで少し長押し
・人参：かたいので、もう少し長押し
・牛蒡：とてもかたい。0.5秒しっかり押し切る
・大根：太くてとてもかたい。1秒押し切る
・前の野菜で7,000点を取ると、次の野菜に挑戦できる

■ 気持ちいい手ごたえ
・シャキッ、トン！の包丁の音、神業のキラーン
・薄く切った輪切りほど透けて見え、まな板に積み上がっていく
・称号は「きゅうりに負けた人」から「伝説のきゅうり仙人」まで

■ その他
・指1本で遊べるので、ちょっとしたすきま時間に
・自己ベストを野菜ごとに保存
・結果を友だちにシェア
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

さあ、包丁を握って。きゅうりとの30秒勝負だ。
```

## Play Console「アプリのコンテンツ」の回答の目安

- **プライバシー ポリシー**: https://techgym.jp/privacy-policy/
- **広告**: 「はい、広告を含みます」（バナー・インタースティシャル・リワード）
- **アプリのアクセス権**: 「制限なし（ログイン不要）」
- **広告 ID**: 「使用する」（目的は「広告またはマーケティング」と「アナリティクス」）
- **ターゲット ユーザー**: 13 歳以上（13 歳未満を含めると広告に制限がかかる）
- **データ セーフティ**: アプリ自体は個人情報を集めないが、Google AdMob が「デバイスまたはその他の ID（広告 ID）」と「アプリの操作（広告の表示・クリック）」を広告とアナリティクスの目的で収集・共有する。通信は暗号化されている。※ AdMob の公式ガイドに従って最終確認すること
- **コンテンツのレーティング**: ゲーム → 包丁で野菜を切る描写のみ（暴力・流血・人物への危害はなし）
- **カテゴリ**: ゲーム → カジュアル
